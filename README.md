# Morse Code LED

The board will be able to transmit a repeating message using one LED through morse code. The message should be able to changed by changing one line of the program.

## Hardware
- ESP32 DevKit
- ESP32 Camera Extension
- Battery
- 330Ω Resistor
- Red 2V LED

## Wiring
| Pin  |   Connects to    |      Notes      |
|------|------------------|-----------------|
| IO13 | LED → 330 Ω →GND | Red, High is ON |
